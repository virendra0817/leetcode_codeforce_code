// ===================================================
// Problem  : Remove Duplicates from Sorted Array
// Platform : Leetcode
// Link     : https://leetcode.com/problems/remove-duplicates-from-sorted-array/
// Difficulty: Easy
// Language : python3
// Runtime  : 3 ms
// Memory   : 20.4 MB
// Date     : May 8, 2026
// ===================================================class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        replace = 1 
        for i in range(1,len(nums)):
            if nums[i-1]!= nums[i]:
                nums[replace] = nums[i]
                replace +=1
        return replace
